# Specification Quality Checklist: 参照ダッシュボード統合

**Purpose**: 参照HTMLとの差分、合計処理時間、顔・声対応条件の要件品質を確認する

**Created**: 2026-08-09

**Feature**: [spec.md](../spec.md)

## Content Quality

- [x] 実装方式ではなく、参照画面で達成する利用価値を記述している
- [x] 現行アプリと参照HTMLの差分を明示している
- [x] 現行のモデル・パラメータを参照HTMLの例示値と区別している
- [x] 指定された参照HTMLを画面仕様の優先ソースとして明記している
- [x] 以前の `docs/current-screen.html` を採用しない範囲を明記している
- [x] 識別ごとの合計処理時間と、表示しない過程時間を明示している
- [x] 顔/音声の識別履歴テーブルをプレビュー画面から除外している

## Requirement Completeness

- [x] 要件は受入シナリオで検証できる
- [x] 未実行、無音、複数話者、権限なしの境界条件を記述している
- [x] 取得できない端末項目を固定値で補わない方針を記述している
- [x] 成功条件を数値または確認可能な状態で定義している
- [x] 顔匿名IDと話者匿名IDは、単独話者かつ区間重複率0.60以上の場合に限り、セッション内の一時的な対応候補として表示し、永続リンクしない（FR-014/FR-015）

## Scope and Traceability

- [x] モデル置換を本要件の範囲外として明示している
- [x] 対応候補をセッション内の一時情報として定義している
- [x] RTFをメイン画面に表示しない方針を定義している
- [x] 顔識別・話者識別の結果表の列、平均値、しきい値、発話時間を定義している
- [x] FACE/VOICEイベントログの出力形式と一致・不一致表示を定義している
- [x] 次工程で必要な実測値・追加計測を区別している

## Notes

- 顔⇔話者の対応は、画面上の一時的な対応候補表示に限定し、永続的な顔・話者リンクは作成しない。
- その他の要件は、FR-011の方針決定後に計画化できる。
