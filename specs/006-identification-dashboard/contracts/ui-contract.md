# UI Contract: 横画面識別ダッシュボード

## 共通

- MainActivityは横画面固定。
- 起動先は顔識別。
- 顔・音声切替、開始／停止、初期化、パラメータ設定、モデル設定を常に到達可能にする。
- 利用者向け文字列は日本語。固有名詞と一般略語は原表記可。
- 新しいアプリプロセスの起動時は前回の顔ID・話者IDを削除し、完了するまで識別画面を開始しない。
- Activity再生成、画面切替、一時的なバックグラウンド移行では同一セッションの顔ID・話者IDを維持する。

## 識別画面

- 左: カメラ映像または音声状態。
- 音声の左領域: 縦軸が0～100%の正数の音量レベル、横軸が秒単位の時間となるブロック時系列。利用者の横スクロール後は自動追従を停止。
- 中央: パフォーマンス表と識別結果表。各表は列方向へ横スクロール可能。
- 顔識別結果表の見出しは`識別結果表（直近50フレーム）`、音声識別結果表の見出しは`識別結果表（直近50発話）`とする。
- 識別結果表: 直近50件を上限とし、ラベルを行、ID一致率を固定列、識別時刻を列、時刻セル内をIDとする。
- 音声識別結果表にはVADで確定して話者識別処理を完了した発話だけを追加し、雑音・無音および音声データ自体は保持しない。
- 各時刻セル: 一致率上位3件を`ID (類似度)`の3行で表示し、不足分は`―`とする。
- パフォーマンス表: 現在・平均・最大の3行。
- パフォーマンス表は識別結果表より狭いセル幅を使い、CPU・メモリ・fps・msの単位をヘッダーへ集約する。
- 顔性能上位ヘッダー: `計算負荷`（CPU・メモリ）、`顔識別のFPS`（顔検出・顔照合・合計）。
- 話者性能上位ヘッダー: `計算負荷`（CPU・メモリ）、`RTF`、`話者識別（ms）`（発話区間検出・特徴量抽出・話者照合・合計）、`入力録音長（ms）`、`入力音声長（ms）`の順。RTFの表内2行目だけを`話者識別の合計/入力音声長`とし、同じ説明を表外へ表示しない。
- ID一致率: 最頻IDの回数を総検出ID回数で割る。
- 右下: 小型サンプル動画。
- 縦スクロールなしで主要領域を同時表示する。
- 識別・設定・モデル設定・端末診断の各画面にある左上48 dpの非表示領域は、長押し時だけアプリ終了処理を起動し、単タップでは反応しない。

## 動画

- 設定で`非表示`、`20MB`、`200MB`から1つを選択する。
- 選択時は1本だけ小さく表示し、自動で繰り返し再生する。
- 初期ミュート。識別入力へ混入させない。
- 動画名は`20MB`、`200MB`だけを表示し、「ミュート」は表示しない。

## パラメータ設定

- モデル項目を表示しない。
- 各行タップで用途、影響、初期値、範囲を一時表示する。
- 複数サンプル取得は既定OFF。
- 顔の特徴点表示は既定OFF。OFFでも識別処理は継続する。
- 負荷検証動画は既定で非表示。表示時も1本だけ選択する。
- `基本`、`顔検出`、`顔ラベル追跡`、`発話検出`、`音声品質`、`話者ラベル追跡`をこの順で1つの一覧にする。カテゴリ選択ボタンは表示しない。
- 基本は共通・顔識別・話者識別の3列。各詳細カテゴリは見出しと高密度な複数列で続ける。
- パラメータ一覧だけを上下スクロール可能にし、保存列は固定する。
- パラメータ設定画面とモデル設定画面のトップバー操作ボタンは右側にまとめる。
- 同一セクションのカード高を揃え、各カード内の項目群は縦中央寄せにして上下余白を等しくする。
- 顔検出では、YuNet選択時だけ検出スコア・NMS・最大候補数、ML Kit選択時だけ最小顔サイズを表示する。
- 16 kHz、モノラル、PCM16、モデル入力サイズ、特徴量次元、VAD窓サイズ、推論スレッド数は表示しない。

## モデル設定

- 4区分それぞれ1プルダウン。
- 候補は実行可能な`モデル名／推論基盤名`セットだけ。
- 実行不能な保存済みセットは暗黙変更しない。
