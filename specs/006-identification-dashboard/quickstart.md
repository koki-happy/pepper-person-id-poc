# Quickstart: 横画面識別ダッシュボード検証

## 1. ビルド

```powershell
.\gradlew.bat testBenchmarkDebugUnitTest -PtargetAbi=arm64-v8a
.\gradlew.bat assembleBenchmarkDebug -PtargetAbi=arm64-v8a
```

## 2. スマホ受入

対象: `192.168.10.111:42095`

1. ARM64 APKをインストールして起動する。
2. 横画面固定、初期顔識別、顔／音声切替を確認する。
3. 基本と全詳細カテゴリ、各パラメータ説明、複数サンプル既定OFF、条件付き顔検出項目、モデルセットプルダウンを確認する。
4. 設定値を保存して画面を再表示し、値が復元されることを確認する。モデル契約値7項目がパラメータ画面にないことを確認する。
5. 負荷検証動画の初期値が非表示であること、20MB・200MBを切り替えると選択した1本だけが右下で無音再生されることを確認する。
6. 音量グラフの縦軸が0%、50%、100%であることと、パフォーマンス表のセルが内容を保ったまま縮小されていることを確認する。
7. 話者表が計算負荷、RTF、話者識別（ms）、入力録音長（ms）、入力音声長（ms）の順で、RTFの2行目が`話者識別の合計/入力音声長`であり、単位がデータセルに重複しないことを確認する。
8. UIツリー、スクリーンショット、crash logを保存する。
10. 顔画面に`識別結果表（直近50フレーム）`、音声画面に`識別結果表（直近50発話）`が表示され、51件目の追加で最古の結果が削除されることを確認する。

## 3. Pepper受入

スマホ項目がすべて合格した後だけ実施する。対象: `192.168.10.106:5555`

```powershell
.\gradlew.bat assembleBenchmarkDebug -PtargetAbi=armeabi-v7a
```

1. ARMv7 APKをインストールして起動する。
2. スマホと同じ領域配置、操作、動画再生を確認する。
3. カメラ・マイク入力、識別開始、画面切替、crash logを確認する。
